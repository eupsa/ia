# Histórico de versões

Este projeto usa tags para marcar etapas verificáveis. As datas abaixo seguem o horário de America/Bahia.

## v0.17.0 — documentação do parecer · 7 nov. 2026

- Critérios de viabilidade, fórmulas de requisições por minuto, fila e timeout documentados.
- Guias da interface e da API atualizados para os novos campos do relatório.

## v0.16.0 — parecer final do diagnóstico · 7 nov. 2026

- Relatório com avaliação de viabilidade, concorrência e ritmo sugerido por cenário.
- Sugestão explícita de fila e timeout, com fórmulas e limitações documentadas.

## v0.15.0 — guia da interface · 7 nov. 2026

- Documentação de todas as áreas, painéis e controles do site, incluindo estados, dados salvos e erros comuns.

## v0.14.0 — CI atualizada · 7 nov. 2026

- Ações oficiais do GitHub atualizadas para o runtime Node.js 24.
- Permissão do workflow limitada a leitura do repositório.

## v0.13.0 — documentação para código aberto · 7 nov. 2026

- Licença MIT, referência da API, guia de implantação, contribuição e segurança.
- README com índice dos guias, limites do projeto e dependências externas.

## v0.12.0 — preparo para publicação · 7 nov. 2026

- CI para testar e compilar em pushes e pull requests.
- Segredo próprio do SearXNG obrigatório nos perfis HTTPS.
- Controle **Internet** deixa de disponibilizar `web_search` ao modelo quando desativado.

## v0.11.0 — documentação inicial · 7 nov. 2026

- README público e metodologia do diagnóstico de carga.

## v0.10.0 — diagnóstico automático · 7 nov. 2026

- Cenários fixos de latência, contexto e capacidade, com parada adaptativa.
- Relatório real do Qwen3 0.6B medido no Docker Desktop.

As tags anteriores documentam a evolução do chat, RAG, ferramentas, internet, interface e implantação Oracle ARM64.
